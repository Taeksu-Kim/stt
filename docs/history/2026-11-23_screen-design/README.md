## 무엇이 문제였나 → 어떻게 고쳤나
- **구현 첫 화면의 결함 3개 (직접 캡처를 보고 찾음)**: 시간 눈금 "00:00"이 재생 속도 칸 위로 내려감, 실시간 "끝내기" 버튼이 사라짐 — 둘 다 **CSS 클래스 이름 충돌**
  (`.first`가 첫 사용 화면과 눈금에, `.acts`가 행 동작과 배너에). 이름을 나누고 단독 선택자 중복을 스크립트로 검사. 날짜 "11월일 23" — 문자열 치환 오류.
- **평가자 1 (새 맥락)**: ⑦ "화자 정리 수단이 없다" → 화자 이름 칸 팝오버(이름 붙이기 + **같은 사람 합치기**, API `POST …/speakers/{label}/merge`).
  "확인 안 한 줄을 찾으려면 눈으로" → 탭(모든 문장 / 확인 안 함 / 고친 문장) + `N` 다음 확인 안 한 줄. 신뢰도 표시는 **데이터 없음** (Qwen이 신뢰도를 내지 않음 — 지어내지 않음).
- **평가자 1 ⑧**: "중간(mid-A) 쪽, 콘셉트가 트랙 한 띠에만, 목록은 paper_analyst와 같은 템플릿", "Anna 청록 = 주 색 청록 (규칙 2 어긋남)", "굵은 시각이 선택으로 읽힘" →
  구조 회차 2: 주 색을 먹(무채색)으로 — 색은 화자·상태에만 / 트랙 블록이 **확인한 만큼 진해짐**, 고친 눈금은 그 화자 트랙 위 / 목록 작업마다 **작은 테이프** /
  추정 시각은 `≈` / 녹음 길이·엔진 이름 중복 정리 / 실시간 배너를 재생 줄 자리로 / 확인 열을 맨 앞으로 / 주 동작 = "다음 확인 안 한 줄"(채움).
- **마감 1 (새 맥락 작업자)**: 재생 줄 버튼 모양 통일, 화자 열 내용 폭(104→63px), `≈` 고정 칸, 목록 상태 아이콘, 실시간 "다음 줄을 듣는 중" 꼬리 줄, 간격 토큰(4px 단계 밖 0), 목록 폭 조절.
- **최종 평가 1**: "O1(전문가) 쪽이되 한 칸 아래, 잘 만든 시안 상단", 강점 4개 중 3개 남음 → 마감 2: 범례 견본을 실물 색으로, 산문 숫자 비례 숫자, 받아 적지 않은 작업은 점선 테이프,
  연필은 hover 때만, 팝오버 입력칸 폭(옛 규칙이 덮어씀), 확인 표시를 채운 원 → 체크, "전체 다시 받아 적기"를 가볍게.
