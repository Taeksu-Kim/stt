## 콘셉트
평균 틀: 왼쪽 노트 목록 + 가운데 말풍선/문단(화자 동그라미 아바타 + 시각) + 아래 재생 막대 + 오른쪽 요약 패널.
주제의 세계: 녹취록·속기록(줄 번호), 방송 편집 대본(여백 타임코드), 교정지와 교정 부호, 테이프·멀티트랙, 파형, 자막 카드, 희곡 대본.

| 후보 | 한 줄 | 데이터가 무엇의 성질로 | 위험 |
|---|---|---|---|
| **A 사물 — 녹취 교정지 (추천)** | 받아 적은 글은 책상 위 교정지 한 장, 사람은 교정자 | 조각 경계 시각 = 잉크, 추정 시각 = 연필 회색 / 사람이 고친 글 = 교정 빨강(지운 줄 + 넣은 글) / 화자 바뀜 = 종이 밖으로 나온 색인 탭 / 확인 = 오른쪽 여백 체크 / 재생 위치 = 읽는 자(가로 띠) | 종이 소품이 늘면 "꾸민 화면" — 소품은 위 다섯 성질만 |
| **B 시간 — 멀티트랙 테이프 (차선)** | 녹음 전체를 화자별 트랙으로 펼치고 아래에서 읽는다 | 발화 길이 = 블록 길이, 침묵 = 빈 테이프, 보이는 범위 = 창 | 트랙이 첫 화면 1/3 차지, 1시간 넘으면 블록이 가늘어짐 |
| C 데이터 모양 — 파형 척추 | 가운데 세로 파형, 화자별로 좌우에 문장 | 소리 크기 = 파형 폭, 쉼 = 빈 척추 | 채팅처럼 읽힘, 가로폭 낭비 — 거르기 "평균 틀이 바깥에 남지 않았나"에 걸림 |
| D 말·형식 — 희곡 대본 | 이름 가운데, 대사, [웃음] 지문 | 화자 = 이름 줄, 비언어 = 지문 | 형식 흉내(신문 1면 = 별로와 같은 모양), 시각 자리 애매 — 버림 |
| 안전안 — 3단 | 목록 / 문장 표 / 재생 막대 | 없음 | 그 분야 평균 — B의 아래 표가 사실상 이것 |

## 브리프 (맨 위 다섯 줄 — 사용자 확인)
- **콘셉트**: 녹취 교정지 — 시각의 확실함은 잉크와 연필로, 사람의 손길은 교정 빨강으로만.
- **핵심 가치**: 받아 적은 글을 소리와 맞대어 빠르게 확인하고 고쳐, 근거로 인용할 수 있는 녹취록을 만든다.
- **주인공과 밀도**: 교정지(문장 + 여백 시각 + 화자 탭)와 아래 테이프 줄. 촘촘 — 1280 첫 화면에 15~20문장.
- **판정 → 구조**: 결과 화면은 해당 없음. 작업 목록만 — 손이 필요한 것이 위 (듣는 중 → 확인 중 → 확인 끝 → 말소리 없음).
- **테마**: 메인 컬러 고정 (남색 잉크 셸 #1F3A68 + 차가운 회색 책상), 다크모드 없음 — 확인 필요.

## 흐름
들어옴(작업 목록) → 파일 올리기 또는 실시간 시작, A2A로 들어온 일은 목록에 "A2A + 보낸 쪽"으로 보임 → 받아 적는 동안 진행 → 교정지에서 듣고 확인·고침·화자 이름 →
내려받기 / 다른 에이전트는 같은 결과를 A2A로 받음(`reviewUrl` = 이 교정지) → 다음에 오면 확인 덜 된 작업이 위.
실시간: 같은 교정지에 줄이 아래로 쌓임(연필, 화자 없음, 램프) → 끝나면 최종본(화자·문장 시각)으로 바뀜.
