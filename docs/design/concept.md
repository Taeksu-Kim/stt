# stt 콘셉트 카드 (2026-11-23, 사용자가 시안 B를 고름 — `docs/history/2026-11-23_screen-design/`)

콘셉트: **멀티트랙 테이프** — 녹음 전체를 화자별 트랙으로 펼쳐 놓고, 아래에서 문장으로 읽고 고친다.
왜 이 제품에: 받아 적은 글을 확인할 때 먼저 아는 것은 "누가 언제 얼마나 말했나"이고, 그다음이 문장이다. 트랙이 녹음의 지도, 표가 본문.
인상: 차분한 작업 도구 — 진한 남색 셸 위 흰 작업면, 색은 화자와 상태에만 (스타일 0.3).
평균 틀과 다른 점:
1. 맨 위가 요약 패널·파형이 아니라 **화자별 트랙** (발화 = 블록, 침묵 = 빈 테이프)
2. 화자 아바타·말풍선 대신 **표 한 줄 = 문장 하나** (시각 / 화자 / 글 / 확인)
3. 사람이 고친 곳·확인한 곳이 트랙과 표 양쪽에 같은 표식으로 남는다 (교정 빨강 눈금, 확인한 구간은 진하게 칠해짐)
4. 작업 목록도 테이프 — 작업마다 화자별로 칠한 작은 테이프가 확인한 만큼 진해진다 (회차 2, 평가자: "목록 칸이 다른 프로젝트와 같은 템플릿")

틀 (2026-11-24, 사용자: "레이어나 이런 시각적 요소들을 더 구분하게해서 단순성을 좀 줄이고 … 직관적이면서도 명확하게"):
캔버스(옅은 회색) / 조작 콘솔(왼쪽 어두운 세로 기둥: 로고·올리기·실시간·검색·작업 목록) / 작업면(떠 있는 흰 판) — 작업면 안은
조작층(제목·트랙 계기판·재생 줄, 흰 면 + 아래 그림자)과 읽기층(한 톤 낮은 바닥 위에 탭이 붙은 글 종이 한 장, 최대 960px 열)으로 나눈다.
테이프 헤드(재생 위치 위 시각 표지)·빗금(확인 안 한 구간)·화자 막대(트랙 이름·표 화자 칸·로고가 같은 모양)는 시안 8에서 들어옴.

규칙:
1. 시간은 하나의 축이다 — 트랙·재생 위치·표의 현재 줄·보이는 범위 창이 같은 시각을 가리키고, 하나를 움직이면 나머지가 따라온다. [지킴]
2. 화자 색은 화자에게만 — 트랙 블록·표의 점·화자 이름 글자. 다른 뜻에 화자 색을 쓰지 않는다. [지킴]
3. 빨강은 "사람이 고친 것"에만 — 지운 글·넣은 글·트랙 눈금·고침 개수. 오류는 빨강이 아니라 글로 말한다. [지킴]
4. 시각의 확실함을 표시로 — 추정 시각은 `≈` 를 붙이고 회색. (회차 1의 "굵기"는 선택한 줄로 읽혀 바꿈) [지킴]
5. 진행 중인 것은 같은 트랙 위에서 자란다 — 받아 적는 중·실시간 듣는 중이면 트랙 블록과 표 줄이 늘어난다 (따로 만든 진행 화면 없음). [지킴]

데이터 매핑: 발화 길이 → 블록 길이 / 침묵 → 빈 테이프 / 확인 여부 → 채운 블록(확인) · 빗금(아직) / 화자별 말한 몫 → 트랙 이름 옆 % / 사람이 고친 문장 → 그 화자 트랙 위 빨간 눈금 /
표에 보이는 범위 → 트랙 위 창 / 재생 위치 → 세로 선.
